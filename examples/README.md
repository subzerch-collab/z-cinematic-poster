# Examples

These examples use completely fictional people generated for this repository. They do not reuse the user's private portraits or any third-party watermarked reference images.

- `example-01-source.png` → `example-01-poster.png`: neutral portrait transformed into an abstract black-gold editorial poster with a new silk couture outfit.
- `example-02-source.png` → `example-02-poster.png`: neutral portrait transformed into a rain-wet city poster with tailored formalwear.

The examples demonstrate identity preservation, wardrobe replacement, natural upper-body proportions, unified lighting, high-detail backgrounds, and restrained double exposure. Output will vary by image model and input quality.
